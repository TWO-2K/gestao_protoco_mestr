# AGENTS.md

## Project Context

This is a local React/Vite application. Data is persisted in the browser through IndexedDB. Keep changes focused on the user's request and preserve project conventions.

Start with `README.md` for local setup.

## Key Files

- `src/`: frontend source.
- `src/lib/rabbitDatabase.js`: IndexedDB access and test seed data.
- `src/lib/RabbitContext.jsx`: browser data state and CRUD operations.

## Working Notes

- Use `npm run dev` to start Vite.
- Use `npm run build` and `npm run lint` before finishing code changes.
